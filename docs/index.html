概念

本物を、正しく伝える

“バレエというと、華やかな舞台”を想像しますが、それを支えるのは地味なレッスンとたえまない努力によるものです。踊ることは身体によく、規律正しい訓練は健全な精神をつくり、姿勢や立ち居振る舞いを美しくするのに加え、コントロール力を養います。

ただ気をつけなければならないことは、バレエをやれば必ず美しくなるということではないということです。特にお子様は骨も柔らかく、足先だけの無理な開脚や、身体形成ができる前にトゥシューズを履くこと、難しいテクニックにより、足のラインを崩してしまいかねません。

設備

正しく学べる環境

様々なバレエのパ（動き）を正確に習得し、ポジションの確認をしながら、踊りにつなげられることが重要です。

  • スタジオ

    バレエはまず、まっすぐに立つことから始まります。身体をスクエア（四角）にとらえ、左右を同じ位置・同じ高さに保つために、訓練する場所が四角い形状であること、バーをスタジオに対して直角又は平行に置くことが必要だと考えます。

  • 鏡

    前方と側面から、身体を自分の目で見て確認できるよう、スタジオに対してL字に装備しています。

  • バレエ用の床

    バレエは、滑りやすい床では踊ることが出来ません。かといって、ピルエット（回転）の時にシューズが引っ掛かってしまってもいけません。バレエを踊りやすいリノリウムを使用しています。
